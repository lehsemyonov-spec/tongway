# Tongway

Переводчик для Android: кружок поверх всех приложений. Перетащите его так, чтобы прицел
оказался на тексте, — появится перевод на русский. Перевод делается прямо на телефоне (Google ML Kit).

## Как установить

1. Скачайте [tongway.apk](https://github.com/lehsemyonov-spec/tongway/releases/download/latest/tongway.apk)
   (всегда последняя сборка).
   Если скачивание обрывается, используйте запасную ссылку:
   [tongway.apk](https://raw.githubusercontent.com/lehsemyonov-spec/tongway/apk/tongway.apk).
2. Откройте файл и разрешите установку из неизвестных источников, если телефон спросит.
3. Откройте Tongway и пройдите три шага на главном экране.
