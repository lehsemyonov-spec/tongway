# Tongway — переводчик для Android

## Кто пользователь и как с ним общаться

- Не программист, пишет только с телефона (Android), компьютера нет.
- Общаемся на русском, простым языком, по шагам и без жаргона.
- Перед крупной задачей сначала показать план и дождаться подтверждения.
- Пользователь тестирует на телефоне и описывает проблемы словами и скриншотами.
  Ошибки присылает из экрана «Журнал» (кнопка «Скопировать»).

## Идея

Своё приложение вместо Immersive Translate. Переводит иностранный текст на русский,
в первую очередь с английского. Только Android (на iPhone такое запрещено).
В Google Play не публикуем — ставим `.apk` вручную.

## Этапы

1. ✅ (v1, в работе) Кружок поверх приложений + перевод текста на экране (ML Kit на телефоне).
2. Перевод в строке ввода мессенджера: кружок рядом с полем ввода → меню языков →
   набранный текст заменяется переводом (`ACTION_SET_TEXT`).
3. Фотоперевод: камера → распознавание текста → перевод.
4. Перевод документов: PDF, Word, TXT.
5. Выбор облачных переводчиков и нейросетей по ключу API (ключ хранится только на телефоне).
   Перед подключением проверить актуальные условия и доступность из России.

## Решения по первому этапу

- Механика: **перетащить кружок и отпустить** (вариант А). Прицел рисуется над пальцем
  (на 72dp выше центра кружка), текст ищется под прицелом.
- Переводится **только кусок под прицелом**: самый маленький элемент с текстом в этой точке.
  Если текст длинный, берётся только абзац под прицелом (по координатам символов).
- После отпускания кружок отъезжает к ближайшему краю экрана.
- Убрать кружок — перетащить на крестик внизу. Вернуть — кнопкой в приложении.
- Касание кружка без перетаскивания показывает подсказку.
- Перевод: Google ML Kit Translation на телефоне. Язык определяется ML Kit Language ID
  (порог уверенности 0.7, иначе считаем английским).

## Как устроено

- Всё поверх приложений рисуется окнами `TYPE_ACCESSIBILITY_OVERLAY` из службы
  спец. возможностей. Поэтому отдельное разрешение `SYSTEM_ALERT_WINDOW` не нужно.
- `TranslatorService` — служба спец. возможностей, держит `OverlayController`.
- `ScreenTextFinder` — ищет текст в точке через дерево `AccessibilityNodeInfo`.
- `TranslationEngine` — ML Kit (определение языка + перевод), общий на всё приложение (`App.engine`).
- `AppLog` — журнал в файле `filesDir/log.txt`, экран `LogActivity`.
- Android 13+ блокирует включение спец. возможностей для приложений из `.apk`, пока в
  «О приложении» → ⋮ не нажать «Разрешить ограниченные настройки». Это объяснено на главном экране.
- Текст, нарисованный картинкой, в v1 не переводится (позже: `MediaProjection` + ML Kit Text Recognition).

## Сборка

- В облачной сессии Android SDK скачать нельзя (dl.google.com закрыт), поэтому сборку
  проверяем только через GitHub Actions (`.github/workflows/build.yml`).
- Каждая сборка выкладывает `tongway.apk` в пре-релиз `latest`:
  https://github.com/lehsemyonov-spec/tongway/releases/download/latest/tongway.apk
- `versionCode` = номер сборки GitHub Actions, чтобы новая версия ставилась поверх старой.
- `app/debug.keystore` лежит в репозитории специально: один ключ для всех сборок,
  иначе телефон не даст обновить приложение.
- Версии: AGP 8.7.3, Kotlin 2.0.21, Gradle 8.11.1, compileSdk 35, targetSdk 34, minSdk 26.
